# Security

Copaste is a client-side mod for Cities: Skylines II. It does not connect to the network, does not collect or send data, and stores no custom data in save files. It reads and writes only its own settings and blueprint text files under the game's `ModsData\Copaste` folder.

If you believe you have found a security issue (for example something in blueprint file parsing that could be abused by a shared file), please report it privately through [GitHub's private vulnerability reporting](https://github.com/viktorsx/Copaste/security/advisories/new) rather than a public issue. You will get a reply, and a fix will be published before details are made public.

Only the latest release is supported.
